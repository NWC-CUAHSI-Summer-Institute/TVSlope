# data/

Small curated inputs live here (`slope_treatments.csv`, `study_area_gauges.csv`). The heavy reference layers
(SWORD, FIMBench benchmarks, staged HAND `fimbox_out/`, IRIS, GDW) are **not** in this repo — see `../DATA.md`
for the layout, sizes, and how to fetch the external data archive. `05_work6_3DHRS.ipynb` needs the curated work6
cache (also described in `DATA.md`); `02_study_area.ipynb` and `04_timevary_slope.ipynb` need the full archive.
